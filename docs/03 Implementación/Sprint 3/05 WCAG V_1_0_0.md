# Evaluación de Accesibilidad Web (WCAG)

**Nombre del Proyecto:** EcoLogistica-Lima  
**Nivel de Conformidad Objetivo:** WCAG 2.1 / 2.2 Nivel AA  
**Herramientas Utilizadas:** SonarQube + revisión de accesibilidad UI / Lighthouse (recomendado para validación adicional)

## 1. Resumen de Accesibilidad por Principios
- **Perceptible:** 80% de cumplimiento / Observaciones: algunos elementos visuales requieren mejoras de etiquetado y semántica para asegurar una lectura clara con assistive technology.
- **Operable:** 75% de cumplimiento / Observaciones: se detectan componentes interactivos con manejo insuficiente de foco y controles no accesibles por teclado.
- **Comprensible:** 85% de cumplimiento / Observaciones: la lógica de navegación y contenido es entendible, pero requiere reforzar los textos asociados a controles.
- **Robusto:** 70% de cumplimiento / Observaciones: se requiere mayor consistencia en la semántica y validación de controles conforme a estándares de interoperabilidad.

## 2. Hallazgos Principales y Correcciones

| Criterio de Conformidad | Problema Detectado | Componente Afectado | Solución Aplicada |
| :--- | :--- | :--- | :--- |
| **1.1.1 Contenido no textual** | Falta de etiqueta o texto asociado en elementos interactivos | Header / componentes de UI | Se recomienda añadir textos descriptivos y atributos semánticos para mejorar la identificación por lectores de pantalla |
| **1.4.3 Contraste mínimo** | Riesgo de bajo contraste en elementos secundarios | Botones y controles visuales | Ajustar la paleta de colores y reforzar contraste para cumplir WCAG AA |
| **2.1.1 Teclado** | Elementos no navegables por Tab o con manejo incompleto de foco | Menú desplegable / controles de formulario | Implementar manejo de foco, navegación por teclado y estados visibles para cada control |

### Conclusión
La accesibilidad del proyecto requiere refuerzo en la capa de interfaz, principalmente en etiquetas, foco y contraste. Los hallazgos reportados por SonarQube en fiabilidad y usabilidad son una base útil para priorizar la corrección de estos puntos antes de cierre operativo.
