## 10.2. Justificación Técnica y Criterios de Selección del Stack

La selección de tecnologías para **EcoLogistica-Lima** responde directamente a las restricciones del proyecto (presupuesto tope de S/ 12,850.00, plazo estricto de 16 semanas y equipo de 5 integrantes), garantizando alta mantenibilidad, escalabilidad en la nube y un enfoque de costo eficiente mediante el uso de tecnologías Open Source y capas gratuitas/estudiantiles.

### 10.2.1. Criterios de Selección Metodológica
1. **Curva de Aprendizaje y Velocidad de Desarrollo:** Uso de frameworks consolidados (React, Flutter, Node.js/TypeScript) para acelerar la entrega de incrementos en sprints quincenales.
2. **Arquitectura Modulo-Desacoplada:** Microservicios y funciones Serverless que minimizan el impacto ante cambios (VAR-03 = 2/5) y permiten pruebas independientes.
3. **Sostenibilidad Financiera:** Adopción de servicios *Pay-As-You-Go* con límites de facturación controlados (AWS Budgets / Vercel Limits) para asegurar cumplimiento de la restricción RES-02.
4. **Resiliencia Operativa:** Estrategia *Offline-First* en el cliente móvil para mitigar problemas de conectividad intermitente en Lima (SUP-01).

## 10.3. Definición Detallada del Stack Tecnológico

| Capa Tecnológica | Tecnología / Herramienta | Versión / Tipo | Justificación de Negocio y Técnica |
| :--- | :--- | :---: | :--- |
| **Frontend Web** | **React.js + Tailwind CSS** | v18+ | Interfaz responsive para despachadores y administradores. Permite renderizado eficiente del panel de monitoreo e integración ligera con mapas. |
| **Aplicación Móvil** | **Flutter (Dart)** | v3.x | Desarrollo multiplataforma nativo optimizado para Android 10+ (RES-04). Facilita el manejo de ubicación en segundo plano y almacenamiento local. |
| **Backend / API** | **Node.js (NestJS / TypeScript)** | v20 LTS | Arquitectura de microservicios limpia (Clean Architecture), altamente estructurada, ideal para integrar módulos de ruteo, autenticación y $CO_2$. |
| **Base de Datos Relacional**| **PostgreSQL + PostGIS** | v16 | Almacenamiento de usuarios, pedidos, vehículos y consultas geoespaciales avanzadas (cálculo de distancias, polígonos urbanos y rutas). |
| **Caché y Mensajería** | **Redis** | v7.x | Caché geoespacial de alta velocidad para reducir consumo de cuotas de APIs externas de mapas (RSK-01) y gestionar sesiones. |
| **Servicios Geoespaciales** | **OpenStreetMap + GraphHopper API** | Open Source | Motor de enrutamiento ecológico personalizable con soporte fallback a Google Maps API según disponibilidad de cuota. |
| **Infraestructura Cloud** | **AWS Serverless / Vercel / Render** | Cloud PaaS | Despliegue elástico de APIs y bases de datos administradas, garantizando disponibilidad $\ge 99.5\%$ (RNF-01) a costo mínimo. |
| **Seguridad y Auth** | **JWT + OAuth 2.0 (Auth0/Supabase)** | Estándar | Autenticación robusta y encriptación de tokens para cumplir con la Ley N° 29733 de Protección de Datos Personales (RES-03). |
| **DevOps & CI/CD** | **GitHub Actions + Docker** | Cloud/CLI | Automatización de pruebas unitarias/integración ($\ge 80\%$ cobertura) y despliegues continuos sin interrupción de servicio. |
