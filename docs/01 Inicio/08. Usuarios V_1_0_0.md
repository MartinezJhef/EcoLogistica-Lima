### 4.2. Políticas Basadas en Atributos (ABAC - Attribute-Based Access Control)

Para mitigar riesgos operativos y proteger datos confidenciales según la Ley N° 29733, se aplican las siguientes reglas contextuales complementarias:

1. **Restricción por Geocerca (Conductor):** Un conductor solo puede marcar una orden como `ENTREGADO` si el atributo de telemetría `distancia_al_destino <= 100 metros`.
2. **Restricción Horaria (Operador):** La creación y reprogramación de rutas solo está habilitada dentro de la ventana de operación logística configurada (05:00 a 22:00 horas local).
3. **Propiedad de la Información (Cliente Final):** El cliente solo puede consultar la orden si el token de rastreo criptográfico recibido vía SMS/Email coincide con el `hash_pedido` consultado.
